Simply Sans Bold is bundled here as CustomFont.ttf and is the default
font for this addon (same font used in Xal's Quest Compass). It's
licensed under the SIL Open Font License, included as
SimplySans-LICENSE.txt, which permits bundling with software.

To use your own font instead, replace CustomFont.ttf with any .ttf file
you own the rights to (keep the exact filename "CustomFont.ttf"), then
in the addon's Settings panel (/xcp options -> Colors) make sure
"Custom (Fonts/CustomFont.ttf)" is selected in the Font dropdown -- that
entry now points at whatever file is in this folder. Reload UI (/reload)
if a font change doesn't apply immediately.

If the file is ever missing or invalid, the addon automatically falls
back to the default stock Friz Quadrata font.

FiraSans-Medium.ttf is also bundled here, used for the fixed/branded body
text on the What's New splash (window titles use CustomFont.ttf above;
this is body copy specifically, same as Xal's Quest Compass). Licensed
under the SIL Open Font License, included as FiraSans-LICENSE.txt.
